# Ejercicio Prácticas Introducción a Físicas 3D 

Repositorio central de las prácticas de Introducción a Físicas 3D en Unity. Este proyecto recopila una serie de ejercicios prácticos diseñados para comprender y dominar el motor de físicas de Unity (Nvidia PhysX), tanto desde la configuración de componentes en el editor como desde la programación en C#.

El trabajo está dividido en dos bloques principales:

## Índice de Contenidos

### 1. [Experimentación con Rigidbody y Colliders](https://github.com/guillrl1/IIII-Practica-3-Fisicas/blob/main/Fisicas3D/IntroduccionFisicas.md)
En este documento se exploran 9 situaciones físicas diferentes configurando únicamente los parámetros del editor (Rigidbody, Is Kinematic, Mass, Colliders, Physics Materials y Triggers). Estudiaremos cómo reaccionan un plano, un cubo y una esfera ante distintas condiciones de masa, gravedad y tipo de colisión.

### 2. [Programación de Físicas con Scripts (C#)](https://github.com/guillrl1/IIII-Practica-3-Fisicas/blob/main/Fisicas3D/Fisicas3D.md)
En esta sección se resuelven 6 ejercicios prácticos que requieren el uso de código para interactuar con el motor de físicas. Incluye el movimiento controlado de un personaje, la detección de colisiones (`OnCollisionEnter`), el uso de áreas de efecto (`OnTriggerEnter`), la manipulación de la Layer Collision Matrix y la simulación de colisiones matemáticas sin el uso de Rigidbody.
